# Informe de Actualización — V FSA 0012
**Fecha:** 2026-06-05

---

## Solicitud del usuario

En Gastos Comunes, el contenedor de la sección era demasiado angosto en móvil. Se solicitó:
1. Que ocupe casi todo el ancho de la pantalla en móvil
2. Que las personas añadidas se ordenen en dos columnas (dos personas por fila), añadiendo más debajo si hay más personas

Solo en móvil, sin afectar desktop.

---

## Modificación realizada

### CSS — bloque `@media (max-width: 768px)` nuevo para Gastos Comunes (`index.html`)

```css
@media (max-width: 768px) {
  #comunes-cards {
    padding: var(--space-sm) 4px;
  }
  .item-people-panel {
    display: grid;
    grid-template-columns: 1fr 1fr;
    align-items: start;
  }
  .person-chip {
    width: 100%;
    box-sizing: border-box;
  }
  .person-chip .person-chip-name {
    width: 100%;
    min-width: 0;
  }
  .person-chip-add {
    grid-column: 1 / -1;
    justify-self: start;
  }
}
```

| Regla | Efecto |
|---|---|
| `#comunes-cards { padding: 4px }` | Cards llegan casi al borde de la pantalla en móvil |
| `.item-people-panel { grid; 1fr 1fr }` | Personas en cuadrícula de 2 columnas |
| `.person-chip { width: 100% }` | Cada chip ocupa toda la celda del grid |
| `.person-chip-add { grid-column: 1/-1 }` | El botón "+" queda en línea propia al final |

**Alcance:** Solo `@media (max-width: 768px)` — desktop no se ve afectado.
