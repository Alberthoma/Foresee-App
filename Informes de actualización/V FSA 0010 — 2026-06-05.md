# Informe de Actualización — V FSA 0011
**Fecha:** 2026-06-05

---

## Solicitud del usuario

El botón activo del tab-bar (`.tab-btn--active`) se veía demasiado transparente. Se solicitó aplicar el mismo efecto de cristal esmerilado del `#action-bar` pero más opaco.

---

## Modificación realizada

### CSS — `.tab-btn--active` (`index.html`)

```css
/* Antes */
background-color: rgba(79, 143, 255, 0.15);
border-color: var(--color-accent);
box-shadow:
  0 0 8px rgba(79, 143, 255, 0.55),
  0 0 16px rgba(79, 143, 255, 0.3),
  0 0 24px rgba(79, 143, 255, 0.15);

/* Ahora */
background: color-mix(in srgb, var(--color-accent) 28%, var(--color-surface));
backdrop-filter: blur(8px);
-webkit-backdrop-filter: blur(8px);
border-color: var(--color-accent);
box-shadow:
  0 0 8px color-mix(in srgb, var(--color-accent) 55%, transparent),
  0 0 16px color-mix(in srgb, var(--color-accent) 30%, transparent),
  0 0 24px color-mix(in srgb, var(--color-accent) 15%, transparent);
```

- **28% del accent sobre surface** — visiblemente más opaco que el 15% anterior, mantiene coherencia con el tema (claro/oscuro)
- **backdrop-filter: blur(8px)** — efecto cristal esmerilado igual al action-bar
- **box-shadow con `color-mix`** — usa `var(--color-accent)` en lugar de valores rgba hardcodeados, respeta el modo claro/oscuro
- `-webkit-backdrop-filter` — compatibilidad con Safari/iOS
