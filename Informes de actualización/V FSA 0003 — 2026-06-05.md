## Modificación realizada

### Swipe horizontal entre tabs — `index.html` (junto al listener del tab-bar)

Se añadió un IIFE (función autoejecutable) con dos event listeners en `document`:

**`touchstart` (passive):** guarda la posición inicial X e Y del toque.

**`touchend` (passive):** evalúa el gesto aplicando cuatro guardas antes de actuar:

| Guarda | Motivo |
|---|---|
| `body.classList.contains('view-dashboard')` | No navegar cuando está en la pantalla de inicio |
| `document.querySelector('.modal-overlay.active')` | No navegar con un modal abierto |
| `e.target.closest('.table-wrapper, input, textarea, select')` | No interferir con scroll horizontal de tablas ni con campos de formulario |
| `Math.abs(dx) < 50 \|\| Math.abs(dx) <= Math.abs(dy)` | Mínimo 50px y gesto predominantemente horizontal (no vertical) |

Si pasa todas las guardas:
- **Swipe izquierda (dx < 0):** activa el siguiente tab en el orden definido
- **Swipe derecha (dx > 0):** activa el tab anterior

### Orden de tabs
`registros → voz → proyeccion → recurrentes → gastos-comunes → tarjetas → saldos → reportes → presupuesto → configuracion`

Los listeners usan `{ passive: true }` para no bloquear el scroll del navegador y garantizar rendimiento óptimo.
