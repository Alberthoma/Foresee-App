# Informe de Actualización — V FSA 0017
**Fecha:** 2026-06-06
> Corrige los intentos fallidos de V FSA 0015 y V FSA 0016.

---

## Solicitud del usuario

Modal de selección de categorías en móvil: debe ajustarse al contenido (compacto con pocos íconos), activando scroll solo cuando los íconos excedan la altura máxima de pantalla (~90vh).

---

## Por qué fallaron V FSA 0015 y V FSA 0016

### V FSA 0015
`height: auto` en `.modal-box` correcto, pero `modal-body` heredaba `flex: 1 1 0` (flex-basis: 0) → colapsaba a casi nada en contenedor de altura automática.

### V FSA 0016
Se usó `flex: none` (`flex: 0 0 auto`) en `modal-body`. El problema: `overflow-y: auto` solo se activa cuando el elemento tiene una **altura forzada desde arriba**. Con `flex: none` sin `min-height: 0`, el elemento crecía con su contenido pero nunca podía **contraerse** para activar el scroll. El scroll terminaba en el `.cat-grid` (con su propio `max-height: 75vh`), no en el `modal-body`.

---

## Causa raíz identificada

El patrón correcto de flexbox para "crece con contenido hasta un límite y luego hace scroll" requiere **tres reglas combinadas** en el hijo scroll:

| Regla | Por qué |
|---|---|
| `flex: 1 1 auto` | Puede crecer (con contenido) Y contraerse (cuando el padre llega a `max-height`) |
| `min-height: 0` | **Clave**: sin esto el navegador impide que un hijo flex se contraiga por debajo de su contenido natural; `overflow-y: auto` nunca se activa |
| `overflow-y: auto` | Se activa únicamente cuando el elemento está siendo contraído por debajo de su tamaño natural |

---

## Modificaciones realizadas

### CSS — `@media (max-width: 768px)` (`index.html`)

```css
/* Antes (V FSA 0016) */
#cat-modal .modal-box { height: auto; max-height: 90vh; }
#cat-modal .modal-body { padding: var(--space-sm); flex: none; }
.cat-grid { grid-template-columns: repeat(3, 1fr); max-height: 75vh; overflow-y: auto; }

/* Ahora (V FSA 0017) */
#cat-modal .modal-box {
  height: auto;
  max-height: 90vh;
  overflow: hidden;         /* limita visualmente a 90vh */
}
#cat-modal .modal-header {
  flex-shrink: 0;           /* el header nunca se aplasta */
}
#cat-modal .modal-body {
  flex: 1 1 auto;           /* crece con contenido, puede contraerse */
  min-height: 0;            /* permite contracción → activa overflow-y */
  overflow-y: auto;
  padding: var(--space-sm);
}
#cat-modal .cat-grid {
  grid-template-columns: repeat(3, 1fr);
  max-height: none;         /* sin límite propio */
  overflow-y: visible;
}
```

**Resultado:**
- Pocos íconos → modal compacto, sin scroll ✓
- Muchos íconos → modal crece hasta 90vh, luego scroll en modal-body ✓
- Header siempre visible y sin comprimir ✓
