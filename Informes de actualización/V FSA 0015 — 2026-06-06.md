# Informe de Actualización — V FSA 0015
**Fecha:** 2026-06-06
> ⚠️ **SUPERADO** — El fix fue incorrecto. Ver V FSA 0016 para la solución correcta.

---

## Solicitud del usuario

En el modal de selección de categorías (sección Registros, móvil), los íconos solo se mostraban en la mitad superior del modal. La mitad inferior aparecía como espacio vacío, obligando a hacer scroll innecesario.

---

## Causa identificada

La regla genérica de mobile fija el alto de **todos** los modales en `height: 90vh`:

```css
@media (max-width: 768px) {
  .modal-box {
    height: 90vh;   /* ← fijo siempre, sin importar el contenido */
  }
}
```

El bloque específico de `#cat-modal` solo sobreescribía `max-height`, sin cancelar el `height: 90vh` heredado. Con pocas categorías (ej. 9–12 íconos), el grid ocupaba ~40–50% del modal y el resto quedaba como espacio vacío en la parte inferior.

---

## Modificación realizada

### CSS — `#cat-modal .modal-box` dentro de `@media (max-width: 768px)` (`index.html`)

```css
/* Antes */
#cat-modal .modal-box {
  max-height: 90vh;
}

/* Ahora */
#cat-modal .modal-box {
  height: auto;       /* crece según el contenido */
  max-height: 90vh;   /* nunca más del 90% de pantalla */
}
```

Con pocas categorías: modal compacto, sin espacio vacío.
Con muchas categorías (>90vh): el `modal-body` activa scroll normalmente gracias a `flex: 1; overflow-y: auto`.

**Alcance:** solo afecta `#cat-modal` en mobile (`≤768px`). Resto de modales sin cambio.
