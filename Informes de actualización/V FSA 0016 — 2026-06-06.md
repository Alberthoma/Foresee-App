---

## Solicitud del usuario

Modal de selección de categorías en móvil: los íconos debían mostrarse sin scroll ajustándose al contenido, activando scroll solo cuando los íconos excedan la altura máxima de la pantalla.

---

## Por qué falló V FSA 0015

`height: auto` en `.modal-box` era correcto, pero el `modal-body` heredaba `flex: 1 1 0` (flex-basis: 0) del bloque genérico mobile. Con flex-basis 0 en un contenedor de altura automática, el elemento colapsa a casi nada → modal quedaba muy pequeño y el contenido se desbordaba generando scroll con pocos íconos.

---

## Modificaciones realizadas

### CSS — `@media (max-width: 768px)` (`index.html`)

```css
/* Antes */
#cat-modal .modal-body {
  padding: var(--space-sm);
}
.cat-grid {
  grid-template-columns: repeat(3, 1fr);
  max-height: none;
}

/* Ahora */
#cat-modal .modal-body {
  padding: var(--space-sm);
  flex: none;          /* no participa en flex-sizing → crece con su contenido */
}
.cat-grid {
  grid-template-columns: repeat(3, 1fr);
  max-height: 75vh;    /* sin límite hasta 75vh, scroll a partir de ahí */
  overflow-y: auto;
}
```

| Regla | Efecto |
|---|---|
| `flex: none` en modal-body | El body crece con su contenido natural, sin colapsar |
| `max-height: 75vh` en cat-grid | Permite crecer sin scroll hasta 75vh (deja ~15vh para header + margen) |
| `overflow-y: auto` en cat-grid | Solo activa scroll cuando los íconos superan 75vh |

**Resultado:**
- Pocos íconos → modal compacto, sin scroll ✓
- Muchos íconos → scroll solo en el grid de categorías, a partir de 75vh ✓
