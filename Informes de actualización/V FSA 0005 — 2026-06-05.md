## Modificaciones realizadas

### 1. CSS — reemplazo completo de estilos de tabla por estilos de card
- Eliminadas reglas `#cc-table` (nth-child, due-danger/warning en `tr`, font-size forzado)
- Eliminada regla mobile `#cc-table { white-space: nowrap }`
- Reemplazada `.cc-row` por `.cc-card` en la lista de transiciones del modo oscuro
- Añadidos ~100 líneas de nuevos estilos: `.cc-cards-grid`, `.cc-card`, `.cc-card-header`, `.cc-card-title`, `.cc-card-actions`, `.cc-card-due`, `.cc-card-bar-*`, `.cc-card-figures`, `.cc-fig-*`, `.cc-card-inputs`, `.cc-input-row`, `.cc-totals-card`, `.cc-totals-grid`, `.cc-total-item`

### 2. HTML — `#section-tarjetas`
- Eliminada `<table class="data-table" id="cc-table">` con `<thead>`, `<tbody>`, `<tfoot>` en tabla
- Reemplazada por `<div id="cc-cards" class="cc-cards-grid"></div>`
- `<tfoot>` reemplazado por `<div id="cc-tfoot" class="cc-totals-card">` con los mismos IDs (`cc-total-amount`, `cc-total-limit`, `cc-total-available`, `cc-total-monthly`) para no romper el JS de totales

### 3. Template — `tpl-cc-row` → `tpl-cc-card`
- Estructura completa nueva: header (nombre + excluir + eliminar), fecha de vencimiento con urgencia, barra de progreso con color dinámico (verde/ámbar/rojo según % usado), figuras clave (adeudado / disponible), grid 2×2 de inputs editables + pago mensual calculado

### 4. `renderCreditCardsTable()` — reescrita
- Usa `tpl-cc-card` en lugar de `tpl-cc-row`
- Calcula `pct = deuda/limite * 100` para la barra
- Mensaje de vencimiento dinámico: "⚠ Vence en N días" / "Día de pago: N"
- Colores de barra: verde (<70%), ámbar (70-90%), rojo (>90%)
- Sin cambios en los totales ni en la lógica de Firestore

### 5. `handleCardDataChange()` — actualizado
- `input.closest('tr')` → `input.closest('[data-card-id]')`

### 6. Event listeners — actualizados
- `cc-tbody` → `cc-cards` (change + click)
